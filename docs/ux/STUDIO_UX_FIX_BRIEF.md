# Бриф: критический UX/UI студии и моделей

**Цель:** передать другой ИИ-модели полный список правок.  
**Продукт:** AI Creative Workstation — рабочее Electron + React + FastAPI приложение (не макет).  
**Ветка:** `feat/ai-first-video-studio-core`  
**Язык UI:** русский по умолчанию (`ru.json`). Английский — полный паритет ключей.  
**Железо:** MacBook Pro M4 Max, 64 GB. Правило: **одна тяжёлая модель в ОЗУ**.

Не делать: ComfyUI / node-graph для Wan. Схема фильма — этапы монтажа, не граф диффузии.

## 0. Контекст со скринов (что видит пользователь сейчас)

### Экран A — «Модели и ресурсы» / Картинка
- ОЗУ: свободно ~30 GB из 64.
- SSD Models: свободно **8.4 GB** из 926 (критически мало).
- Блок «Сейчас в ОЗУ»: текст «в ОЗУ пусто», при этом в шапке **«Движок свободен · Qwen 2.5 14B»**.
- FLUX помечен «выбрана» + «только на диске»; Qwen виден в шапке, но на вкладке «Картинка» нет кнопки выгрузить Qwen.
- В «Доступные модели» у уже установленного SDXL кнопка с сырым ключом **`studio.delete`** вместо «Удалить».
- Кнопка «Скачать» у SDXL Turbo (~7 GB) при 8.4 GB свободных на диске — без предупреждения о нехватке места.

### Экран B — «Видеостудия»
- Превью: портрет + плавающая метка «Нажмите сюда» / «Click here».
- Под превью: иконки разметки + чип **V1**.
- Справа вкладки всё ещё могут мешать (проверить: Фильм / Озвучка на русском).
- **Схема фильма:** сразу несколько оранжевых рамок (Сценарий, Монтаж, Экспорт) — непонятно, что «текущий» шаг.
- Таймлайн: видна дорожка **V2 Сверху**; пользователь не понимает, какая картинка попадёт в MP4.
- Медиа: длинные имена «Запись экрана 2026…», «Product».
- Шапка: Qwen 2.5 14B — без явного «выгрузить» на виду, пока панель движка не открыта.

## 2. Обязательные баги (acceptance)

### 2.1 Сырой i18n-ключ `studio.delete`
**Где:** Студия → Доступные модели → установленная модель.  
**Ожидание:** кнопка «Удалить» / `t('studio.delete')`. Никаких `studio.*` в UI.  
**Проверить:** все кнопки каталога (delete / use / download) рендерят перевод, не ключ.

### 2.2 Противоречие «Qwen в шапке» vs «в ОЗУ пусто»
**Проблема:** шапка показывает модель сценария как будто она «жива», блок RAM говорит «пусто».  
**Ожидание:**
1. `getRuntimeStatus.loaded` + Ollama `/api/ps` согласованы с текстом «Сейчас в ОЗУ».
2. Если Ollama держит веса — строка `ollama:qwen2.5:14b` в списке + кнопка **Выгрузить**.
3. Если весов нет — шапка не должна намекать, что Qwen «в работе». Варианты:
   - «Сценарий: Qwen 2.5 14B (на диске)» когда не в RAM;
   - или «Движок свободен» без имени модели, если ничего не загружено.
4. На вкладке **Сценарий** у активной карточки Qwen — кнопка **Выгрузить**, когда модель в `/api/ps`.

### 2.3 Диск почти полный
При `diskFree < size_needed * 1.15` (или < 12 GB свободно):
- кнопка Скачать disabled или confirm;
- явный текст: «На диске Models осталось X GB, модели нужно ~Y GB».

### 2.4 Схема фильма: один «текущий» шаг
Сейчас оранжевым горят несколько этапов сразу.  
**Правило визуала:**
- **done** — нейтральная рамка / галочка, без оранжевого;
- **current** (ровно один) — оранжевая рамка: первый незавершённый обязательный этап в порядке Материал→…→Экспорт;
- **future** — приглушённый серый;
- клик по этапу по-прежнему открывает/запускает его (не только current).

Не подсвечивать «Монтаж» и «Экспорт» оранжевым только потому что там есть клипы / кнопка экспорта доступна — это не «текущий» шаг пайплайна.

### 2.5 Понятность V1 / V2 в финале
Под превью или у лейбла трека одна короткая фраза всегда:
> «В MP4: основа V1; V2 — только поверх, пока клип на V2 играет.»

Если на курсоре есть и V1 и V2 — превью не должно выглядеть как «пусто + крошечный V2» без объяснения.  
Кнопка «V2 крупно» / «V2→V1» уже есть — не убирать.

### 2.6 Метка «Нажмите сюда» / «Click here»
Пресеты меток на русском UI не должны по умолчанию подставлять английский «Click here».  
Список `QUICK_PRESETS` в `CalloutEditor.tsx` — только RU при `i18n.language` ru; EN — только en.

### 2.7 Имена клипов в Медиа
Не переименовывать пользовательские файлы молча.  
Для отображения: короткий human label (как `clipDisplayName` / `humanizeFileStem`), полное имя — в `title` tooltip.  
«Product» → «Товар» / роль Hero, если это product still.

## 3. UX Studio (модели) — довести до «пульт управления»

1. Блок **Сейчас в ОЗУ** всегда интерактивный:
   - список ключей (ollama / sidecar / job);
   - Выгрузить на каждой строке;
   - «Выгрузить всё / Ollama» как сейчас;
   - если пусто — одна строка: «Ничего в памяти. Выбранная модель = выбор на диске.»
2. Не смешивать «выбрана» и «в ОЗУ» в одном бейдже одного цвета. Два разных сигнала:
   - `выбрана` = будет использоваться при следующем запуске;
   - `в ОЗУ` = сейчас ест память (кнопка Выгрузить).
3. Вкладка Сценарий: рядом с «Активная модель» — Выгрузить, если resident.
4. EngineMonitor: при клике на чип сразу видно Qwen + Выгрузить (уже почти так — проверить на live).

## 4. UX Видеостудия — визуальная чистота

1. **Один primary CTA:** только «Собрать MP4» filled orange. Остальное — secondary/ghost.
2. **Схема фильма:** см. §2.4; подпись без упоминаний ComfyUI / Wan nodes.
3. **Превью-хром:** иконки разметки компактные; слои V1/V2 — отдельная тихая полоска (не спорят с «Собрать MP4»).
4. **Правый inspector:** только русский: Фильм / Озвучка / Клип / Метка.
5. **A1 блоки:** title из начала реплики; при узкой ширине — tooltip с полным текстом (уже есть); не показывать голые «11» / индексы.
6. Не раздувать процесс-мап до drag-and-drop произвольных нод. Допустимо: drop файлов на Материал + клик по этапу.

## 6. Порядок работы для исполнителя

1. Починить `studio.delete` и любые другие сырые i18n-ключи на Студии (grep по UI/`t(` miss).
2. Согласовать шапка ↔ «Сейчас в ОЗУ» ↔ Ollama PS; кнопка Выгрузить Qwen видна без охоты.
3. Предупреждение / блок скачивания при малом diskFree.
4. Схема фильма: ровно один `current`, done/future без оранжевого шума.
5. Пресеты меток по языку; короткие display-имена в Медиа.
6. Короткий smoke: открыть Студию (картинка + сценарий), Видеостудию с V1+V2, кликнуть этапы схемы, выгрузить Qwen из чипа и из Студии.

## 7. Критерии «готово»

- [ ] В UI нет строк вида `studio.delete`, `video.*` как текста кнопок.
- [ ] Если в шапке назван Qwen как загруженный — он есть в «Сейчас в ОЗУ» с Выгрузить; иначе шапка не врёт.
- [ ] Скачивание модели при <~12 GB free на Models — предупреждение или блок.
- [ ] В схеме фильма оранжевым только один текущий этап.
- [ ] Пользователь за 3 секунды отвечает: «что в MP4 — V1 или V2?» (подсказка на экране).
- [ ] На русском UI нет дефолтного английского «Click here» у новой метки.
- [ ] «Собрать MP4» визуально главный CTA; схема не конкурирует оранжевым контуром.
